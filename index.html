Key Ideas

Zeros (roots, x-intercepts): the values of x where f(x) = 0. On the graph, where the parabola crosses the x-axis.
Standard form
f(x) = ax² + bx + c, a ≠ 0.
a, b, c shape and position the parabola.
Factored form
f(x) = a(x − r₁)(x − r₂)
The zeros r₁ and r₂ are visible right away.
Zero Product Property: if A · B = 0, then A = 0 or B = 0. This is the reason we can set each factor equal to zero.

Zeros from Factored Form

Find the zeros of f(x) = 4(2x − 1)(3x + 4)

1. Let f(x) = 0 → 0 = 4(2x − 1)(3x + 4)
2. Divide both sides by the constant 4 → 0 = (2x − 1)(3x + 4) The leading number never changes the zeros.
3. Set each factor to 0 → 2x − 1 = 0 and 3x + 4 = 0
4. Solve → x = 1/2 and x = −4/3
More: 2(x−3)(x+5) → 3, −5 · −1(x+2)(x−4) → −2, 4

Zeros from Standard Form

Rule: factor first, then do the same steps as before.

f(x) = x² + 2x − 15
Need two numbers: product −15, sum +2 → 5 and −3.
(x + 5)(x − 3) = 0
Zeros: −5 and 3
f(x) = 6x² − 7x − 20
(2x − 5)(3x + 4) = 0
2x − 5 = 0 → x = 5/2
3x + 4 = 0 → x = −4/3
Zeros: 5/2 and −4/3

Check: (2x−5)(3x+4) = 6x² + 8x − 15x − 20 = 6x² − 7x − 20 ✓

Ways to Solve ax² + bx + c = 0

A. Extracting roots
Best when there is no x-term: x² = k
B. Factoring
Best when the expression factors nicely.
C. Completing the square
Rewrites into a perfect square (covered in other lessons).
D. Quadratic formula
Works on every quadratic equation.

Tip: Always try the easiest method first, then use the formula if stuck.

Extracting Square Roots

Write the equation as x² = k, then look at k:

k > 0
two real roots: x = ±√k
k = 0
one real root: x = 0
k < 0
no real roots
x² − 16 = 0 → x² = 16 → x = ±4
6x² = 72 → x² = 12 → x = ±√(4·3) → x = ±2√3
s² + 9 = 0 → s² = −9 → no real solution
Check x = 4 and x = −4 in x² − 16: 16 − 16 = 0 ✓

Solving by Factoring

Common monomial
ab + ac = a(b + c)
Difference of two squares
x² − 9 = (x+3)(x−3)
Quadratic trinomial
x² − 5x + 6 = (x−3)(x−2)
  1. Write in standard form (= 0).
  2. Factor.
  3. Set each factor = 0.
  4. Solve each equation.
  5. Check in the original equation.
x² + 9x = −8 → x² + 9x + 8 = 0 → (x+1)(x+8) = 0 → x = −1, x = −8
9x² − 4 = 0 → (3x+2)(3x−2) = 0 → x = −2/3, x = 2/3

The Quadratic Formula

x = [ −b ± √(b² − 4ac) ] / 2a

Steps: 1) standard form 2) find a, b, c 3) substitute 4) evaluate.

Example: 6x − 5 = 6/x → multiply by x → 6x² − 5x − 6 = 0
a = 6, b = −5, c = −6
x = [5 ± √(25 + 144)] / 12 = (5 ± 13)/12
x = 3/2 or x = −2/3

Discriminant D = b² − 4ac: D > 0 → two real roots · D = 0 → one root · D < 0 → no real roots

Word Problems

Steps: understand → write the function → know what is asked → use the easiest method.

Two numbers, sum 18, greatest product
f(x) = x(18 − x) = −x² + 18x
Vertex x = −b/2a = −18/−2 = 9
Numbers: 9 and 9
T-shirts: 40 sold at ₱100; each ₱10 drop sells 5 more
R(x) = (40+5x)(100−10x) = −50x² + 100x + 4000
Vertex (1, 4050)
Max revenue ₱4,050 at price ₱90
Father = 5 × son. Next year father = (son last year)²
5x + 1 = (x−1)² → x² − 7x = 0
x(x − 7) = 0 → x = 7
Son 7, father 35
Note: the vertex of a downward parabola is its maximum.

Summary

  • Zeros = x-values where f(x) = 0 (x-intercepts).
  • Factored form shows zeros directly; standard form → factor first.
  • x² = k → ±√k · Factoring → zero product property · Formula → works always.
  • For maximum/minimum problems, use the vertex x = −b/2a.
  • Always check answers in the original equation.
